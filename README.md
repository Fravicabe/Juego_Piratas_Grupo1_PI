# 🏴‍☠️ Pirate Idle

Idle pirate game inspired by Melvor Idle & Progress Knight.

## Run locally
```bash
npm install
npm run dev
```

## Scripts
- `npm run dev` — dev server
- `npm run build` — production build
- `npm run test` — run tests
- `npm run lint` — lint

## Branching
`main` (prod) ← `dev` (integration) ← `feature/*`. See `PIRATE_GAME_PLAN.md`.
